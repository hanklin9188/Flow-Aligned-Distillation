# Manuscript-source note

The files in this directory are retained as research-artifact material. Public repository documentation intentionally avoids claiming a submission, review, acceptance, or camera-ready status.

The active manuscript source uses an inline `thebibliography`; it does not require the historical `references.bib` file that previously contained an unrelated author-kit template. That misleading file is removed by the repository-hardening change.

Before publishing or redistributing a manuscript snapshot, verify venue policy, anonymization requirements, figure completeness, and source-to-PDF consistency independently from the repository's code/data verifier.
